Python To-Do List

Description:

This is my first Python project as part of the DecodeLabs internship. It allows users to enter three tasks and displays them in a numbered list.

Features:

- Accepts tasks from the user.
- Stores tasks using a Python list.
- Displays tasks with numbers.

How to Run:

1. Install Python.
2. Save the Python code as "todo_list.py".
3. Run the following command:

python todo_list.py

Technologies Used:

- Python
- Lists
- Loops
- User Input
